# Baustellenjournal – LGA BA3

## Veröffentlichung mit GitHub Pages
1. Lade alle Dateien aus diesem Ordner in das Hauptverzeichnis (Root) deines Repositorys hoch.
2. Committe die Änderungen auf dem Branch `main`.
3. Öffne im Repository **Settings → Pages**.
4. Wähle unter **Build and deployment**: `Deploy from a branch`.
5. Wähle Branch `main` und Ordner `/ (root)`, dann **Save**.
6. Nach der Veröffentlichung öffne die angezeigte GitHub-Pages-Adresse in Safari auf dem iPhone.
7. In Safari: Teilen → **Zum Home-Bildschirm**.

## Hinweis zu Daten
Die App speichert Einträge und Fotos derzeit lokal im Browser (localStorage). Die Daten werden nicht in GitHub hochgeladen und nicht zwischen Geräten synchronisiert. Vor dem Löschen von Browserdaten bitte über **Daten exportieren** sichern.
